Use a viewer token for read-only dashboard access. Tokens are never included in this output.

Use a local Kubernetes-authenticated tunnel:
  kubectl --namespace {{ .Release.Namespace }} port-forward --address 127.0.0.1 service/{{ include "geaflow-operator.fullname" . }} 8089:{{ .Values.service.port }}

Open http://127.0.0.1:8089/ and enter the token in the dashboard.
The default NetworkPolicy denies ingress from other pods when supported by the CNI.
For remote access, configure HTTPS and explicit NetworkPolicy rules for approved clients.
