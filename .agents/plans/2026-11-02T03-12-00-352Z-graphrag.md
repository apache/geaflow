# 修复 GraphRAG 设计缺口（P0 → P1 → P2）

## 背景
审计发现 10 个 feature 中 2 个基本达标、6 个部分达标、2 个明显缺口。以下按严重度修复。

## P0（阻断 DoD）

### P0-1 抽取式答案结构化缺失 → EM/F1 恒空
- `RetrievalResponse` 增加 `answer` 字段（String，可空）。
- `RecallService` 在生产路径末尾用 `ExtractiveAnswerConsumer` 生成抽取式答案并回填。
- 让 benchmark 的 `predictedAnswer = response['answer']` 真正可用。
- 位置：`api/model/RetrievalResponse.java`、`service/RecallService.java`、`codec/RetrievalApiJson.java`

### P0-2 benchmark 不发送 primaryConstraint
- `request_body` 增加 `budget.primaryConstraint`（默认 `CANDIDATES`）。
- 新增 `--primary-constraint` 参数，写入 CSV `primaryConstraint` 列。
- 位置：`tools/graphrag/benchmark_http.py`

### P0-3 Citation 溯源字段不全
- `Citation` 补齐 `query`、`mode`、`seed`、`documentId`、`sourceUri`、`hop`、`relationPath`。
- 保持已有 4 参构造器向后兼容。
- 同步 `AnswerApiJson` 序列化。
- 位置：`answer/Citation.java`、`answer/ExtractiveAnswerConsumer.java`、`codec/AnswerApiJson.java`

## P1

### P1-1 BM25 索引字段/返回信息不足
- `LuceneBm25IndexBuilder` 增加 `title`、`entityAliases` 字段。
- `Bm25Hit` 增加 `matchedTerms`、`averageIdf`（或 per-hit idf）。
- 位置：`index/bm25/*`

### P1-2 关联分数分量未进 build metadata
- `GraphBuildMetadata` 增加 hopDecay/degreePenalty/relationPriorities/anchorScoreWeight/edgeStrengthWeight/sourceRelevanceWeight 及版本。
- 位置：`metadata/GraphBuildMetadata.java`

### P1-3 relationPathHit 在 HotpotQA 全空
- gold 侧从 supporting_facts 推导 relation 序列（title 对 → 关系标签），或明确该指标在无关系标注数据集上返回 null 并在 CSV/文档标注不适用。
- 位置：`tools/graphrag/eval/retrieval.py`、`benchmark_http.py`

### P1-4 VECTOR_OVERFETCH 非等预算
- 改为放大 `maxCandidates`（真候选预算），保留 `topK` 不变；重命名注释与 CSV 说明。
- 位置：`tools/graphrag/benchmark_http.py`

### P1-5 无批量检索 CLI
- 新增 `RetrievalBatchCli`：读 JSONL queries，写 JSONL results，走同一 `RecallService`（单一行为真源）。
- 位置：新文件 `retrieval/cli/RetrievalBatchCli.java`（或 `service/`）

### P1-6 minAssociationScore 生产默认 0
- 给 `RetrievalProperties` 设非零默认并接入 plan。
- 位置：`config/RetrievalProperties.java`

## P2
